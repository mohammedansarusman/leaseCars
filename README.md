## Mini Project – Next.js

This is a mini project built using **Next.js** with the main goal of learning and practicing the core features of the framework.

### Features & Concepts Covered
- App Router structure (`layout.js`, `page.js`, `not-found.js`)
- Dynamic routing
- Navigation using Next.js router (`Link`, `useRouter`)
- Responsive UI using **shadcn/ui** and **Tailwind CSS**
- Global state management with **Redux**
- Search and filter with **debounce**
- Form validation implemented manually (without external libraries)

### Tech Stack
- Next.js  
- Tailwind CSS  
- shadcn/ui  
- Redux  

### Purpose
This project was created for learning purposes to gain hands-on experience with Next.js and modern frontend development practices.
